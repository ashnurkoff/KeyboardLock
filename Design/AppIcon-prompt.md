# KeyboardLock app icon prompt

Use case: logo-brand

Asset type: production macOS application icon for a utility named KeyboardLock

Primary request: Create a bold, premium, instantly recognizable icon combining a compact laptop keyboard with a secure padlock. The lock should feel naturally integrated into the keyboard rather than pasted on.

Scene/backdrop: Centered icon object on a deep graphite-to-midnight-navy rounded macOS squircle, transparent outside the squircle.

Subject: Simplified isometric keyboard with a luminous cyan-blue lock rising from the center keys; a subtle fingerprint groove motif on the lock face to hint at Touch ID.

Style/medium: Polished modern macOS 3D icon, crisp geometry, restrained glass-and-anodized-metal materials, subtle depth, professional rather than playful.

Composition/framing: Centered, strong silhouette, generous padding, readable at 16px and 32px, no elements touching edges.

Lighting/mood: Soft studio lighting, cool cyan rim light, calm and secure.

Color palette: Graphite, midnight navy, electric cyan, small violet accent.

Materials/textures: Satin aluminum keyboard, translucent glass lock face, very subtle soft shadow.

Constraints: Square 1024x1024; transparent pixels outside the rounded-square icon shape; no text, letters, numbers, Apple logo, or watermark; keep keys abstract and uncluttered; high contrast at small sizes.

Avoid: Photorealistic MacBook branding, busy key legends, neon overload, childish cartoon style, thin details, excessive gradients.
